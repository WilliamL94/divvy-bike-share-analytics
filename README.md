# divvy-bike-share-analytics
divvy-bike-share-analytics
Divvy Bike Share — End-to-End Data Analytics Project

Project Overview

An end-to-end data analytics project examining Divvy bike-share ridership patterns, customer behavior, and opportunities for data-driven business decisions.
The project includes more than 36 million original records imported into Oracle Database, with a focused analysis of 17,131,207 rides from 2023–2025.

Technologies
*Oracle SQL and Oracle Database
*Python
*Tableau (dashboard in development)
*Data Cleaning and Validation
*Exploratory Data Analysis
*Business Intelligence and Data Visualization

Business Questions
1. How do annual members and casual riders differ in their usage patterns?
2. How do ride durations compare between customer groups?
3. How does ridership change across weekdays and weekends?
4. What hourly patterns distinguish commuting behavior from recreational usage?
5. How does ridership vary across months and seasons?

Project Status
*SQL data preparation and core analysis completed. Interactive Tableau dashboard in development.
